🎉 OLake Fusion has been deployed!

Fusion runs one server pod that schedules Iceberg compaction onto a
Spark-on-Kubernetes optimizer:

  optimizer master   the Spark driver — a lightweight, always-on orchestrator
  optimizer workers  the Spark executors — where compaction actually runs
                     (parallelism: {{ .Values.optimizer.parallelism }}, group: {{ .Values.optimizer.group.name }})

🔌 WIRING OLAKE UI TO FUSION:

  You installed Fusion as its own release. To point an existing olake release at
  it, set the following in the olake chart's values and upgrade that release:

    fusion:
      enabled: true
      releaseName: {{ include "fusion.fullname" . | quote }}
{{- if .Values.auth.existingSecret }}
      auth:
        existingSecret: {{ .Values.auth.existingSecret | quote }}
{{- end }}

  Installing the olake chart with `fusion.enabled=true` instead makes Fusion a
  subchart of that release, wired up automatically - no releaseName needed.

🔍 WATCHING THE OPTIMIZER:

  kubectl get pods -n {{ include "fusion.namespace" . }} -l olake.io/workload={{ .Values.optimizer.master.workloadLabel }}
  kubectl get pods -n {{ include "fusion.namespace" . }} -l olake.io/workload={{ .Values.optimizer.worker.workloadLabel }}
